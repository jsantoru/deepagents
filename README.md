# DeepAgents Chat Platform

Monorepo for a Python DeepAgents backend and a React/Vite frontend. The first slice is a simple chat agent with Tavily web search, Postgres-backed persistence, automated tests, and an admin dashboard that will be expanded incrementally.

## Planned stack

- Python + FastAPI backend
- LangChain DeepAgents for the agent runtime
- Tavily for web search
- PostgreSQL for persistence
- React + Vite frontend
- shadcn/ui component library
- Automated backend and frontend tests

## Current status

Bootstrap in progress. The backend skeleton, local Postgres setup, and test harness land in the first commit.
